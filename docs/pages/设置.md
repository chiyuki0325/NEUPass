# 设置页面

## 页面概览

- 页面名称：设置
- 页面用途：进入应用配色页，并调整一码通亮度、校园跑外观和调试期网络日志选项。
- 路由：从“我的”页面进入设置窗口。
- 页面入口文件：`shared/src/commonMain/kotlin/ink/chyk/pass/features/settings/SettingsScreen.kt`
- 文档维护范围：设置项的展示平台、开关行为、返回入口和本地持久化。

## 页面布局

页面采用单列滚动布局，顶部显示返回按钮和“设置”标题。常规区域依次展示应用配色入口、一码通亮度和校园跑深色模式开关；Android 额外展示创建课表桌面快捷方式。Debug 构建继续展示响应正文、敏感信息遮掩设置，Android Debug 还提供 X5 内核调试入口。

## 用户流程与交互

- 点击返回按钮离开设置页面。
- 点击“应用配色”进入配色二级页。
- 点击设置卡片或卡片右侧开关会立即切换并写入本地设置。
- Android 可请求系统创建课表桌面快捷方式；iOS 与 Desktop 不展示该入口。
- 调试网页入口通过当前平台的 WebView 打开。

## 后端接口清单

无后端接口依赖。页面设置由 `SettingsRepository` 使用本地 MMKV 持久化；创建 Android 桌面快捷方式调用系统 API。

### 缺失接口与接入缺口

无接口缺失或接入缺口。iOS 没有与 Android 固定桌面快捷方式等价的产品入口，因此保持隐藏。

## 可见文案

页面显示“设置”“应用配色”“提高一码通亮度”“校园跑始终使用深色模式”等本地化文案。Debug 构建会显示响应正文、敏感信息遮掩和 Android X5 调试相关文案。

## 页面状态

- 加载中、空状态、校验失败、加载失败：不适用；设置从本地同步读取。
- 正常状态：展示当前开关状态和当前平台适用的操作项。
- 权限不足或不可用：Android 拒绝创建快捷方式时由系统处理；其他平台不展示该入口。
- 成功反馈：设置开关立即更新；Android 创建快捷方式后显示短提示。

## 响应式行为与可访问性

所有宽度均使用可滚动单列卡片。每张卡片包含图标、名称和说明；开关状态同时由系统 Switch 语义暴露，返回按钮提供明确的内容说明。

## 依赖与假设

- 依赖：`SettingsRepository`、MMKV、本地化资源和平台设置扩展。
- 假设：当前 iOS 没有需要单独展示的平台设置项。
- 待确认事项：无。
