# 校园跑页面

## 页面概览

- 页面名称：校园跑
- 页面用途：在应用内打开校园跑 H5 跑步页面。
- 路由：从“应用”区域的校园跑卡片进入独立窗口。
- 页面入口文件：`shared/src/commonMain/kotlin/ink/chyk/pass/features/apps/CampusRunningScreen.kt`
- 文档维护范围：H5 页面加载、定位权限、返回、外观和错误状态。

## 页面布局与交互

页面主体为跨平台 WebView。进入时检查定位权限；授权后加载已认证的校园跑地址，拒绝权限时显示定位权限说明。WebView 使用设置中的校园跑深色模式，并由页面返回操作关闭当前窗口。入口参数缺失时显示参数错误页。

### 缺失接口与接入缺口

无接口缺失或接入缺口。定位授权由 Android/iOS 系统权限管理，不依赖后端接口。

## 页面状态

- 加载中：WebView 负责页面加载展示。
- 正常状态：显示校园跑 H5。
- 权限不足：显示定位权限要求和说明，不加载 H5。
- 加载失败：WebView 保留页面状态；网络恢复时平台 Effect 触发重新连接处理。
- 参数错误：入口未提供 URL 时显示参数错误页。
- 空状态、校验失败和成功反馈：不适用。

## 响应式行为与可访问性

WebView 填满安全区内可用空间；错误页采用居中图像、标题和说明。返回操作由共享窗口导航处理，权限说明同时使用文字表达。

## 依赖与假设

- 依赖：校园跑会话、跨平台 WebView、系统定位权限和网络连接状态。
- 假设：H5 在获得定位权限后自行使用定位能力。
- 待确认事项：无。
