# 我的页面

## 页面概览

- 页面名称：我的
- 页面用途：查看个人资料与余额，上传头像，充值、导出课表、退出登录并进入设置和关于页面。
- 路由：主导航 `profile` 区域。
- 页面入口文件：`shared/src/commonMain/kotlin/ink/chyk/pass/features/profile/ProfileScreen.kt`
- 文档维护范围：个人资料页的数据、操作、反馈和平台文件能力。

## 页面布局与交互

页面顶部显示头像、姓名和学号，下面以卡片列出校园卡余额、网费余额、充值、课表导出、退出登录、设置和关于。页面支持下拉刷新；网络恢复后可自动重试一次。点击头像选择照片并确认后上传；点击学号可复制；课表导出会生成 `.ics` 文件并调用平台分享或日历处理界面。iOS 使用系统照片选择器、短时提示框和分享面板。

### 缺失接口与接入缺口

无接口缺失或接入缺口。复制、照片选择、课表文件导出和状态提示均为平台本地能力。

## 页面状态

- 加载中：资料和余额区域显示加载或骨架效果。
- 正常状态：展示资料、余额和全部可用操作。
- 加载失败：显示可重试错误页；网络恢复后自动尝试刷新。
- 权限不足或不可用：iOS 拒绝照片权限时由系统照片选择流程处理，用户仍可取消并返回页面。
- 成功反馈：复制、头像上传过程与完成状态提供可见提示；导出打开系统处理界面。
- 校验失败：头像未选择时不会进入确认上传流程。

## 响应式行为与可访问性

页面使用可滚动单列列表，窄屏和宽屏保持相同信息顺序。图标和按钮具有内容说明，确认对话框要求用户明确提交或取消。

## 依赖与假设

- 依赖：门户登录会话、课表仓库、系统剪贴板、照片选择器和文件分享能力。
- 假设：iOS 以 JPEG 上传用户选择的照片，文件名为 `avatar.jpg`。
- 待确认事项：无。
