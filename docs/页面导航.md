# 页面导航

主窗口使用common中的Navigation3。四个Tab各持有一个可保存恢复的`NavBackStack`，由同一个`NavDisplay`展示当前Tab的页面。

## 页面层级

- 课表
  - 课表首页：日视图、周视图、考试视图
  - 导入课程
  - 新建／编辑课程
- 一码通
  - 一码通首页
- 应用
  - 应用首页
  - 更多应用
- 我的
  - 我的首页
  - 设置

日／周／考试是课表首页内的视图选择，不增加返回栈。排序、课程详情、关于、退出确认等仍使用对话框。

登录、用户协议、校园乐跑和网页继续由现有`AppWindowNavigator`打开独立平台窗口。

## 返回行为

- 点击任意Tab，先清空目标Tab首页之后的所有页面，再选中该Tab。
- 重复点击当前Tab同样返回该Tab首页。
- 页面返回按钮和系统返回由Navigation3使用同一条出栈逻辑，每次返回一级。
- Tab首页不再出栈，由平台处理主窗口退出。
- 四个Tab的业务ViewModel由主窗口持有；导入和编辑课程的ViewModel由各自Navigation3条目持有，出栈后释放。
- 返回栈和所选Tab支持配置变更后的保存恢复，切换账号时重建导航状态。

## 依赖

采用Navigation3多平台UI`1.1.0`及其运行时，配套Compose Multiplatform`1.10.0`与Lifecycle`2.10.0`。目的地使用可序列化的`NavKey`，common中显式注册序列化类型，不依赖Android反射。
