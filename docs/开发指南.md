# 开发指南

从源码构建NEU Pass的环境准备与各平台常用命令。

## 开始之前

### JDK 21

构建需要JDK 21，确认当前生效版本：

```bash
java -version
```

### Android SDK

Android构建需要Android SDK，并在根目录`local.properties`中指定`sdk.dir`。

### 一言句库

构建无需准备句库，安装包不包含一言句子数据。客户端首次进入课表时，从一言官方Pages地址下载句库，失败时尝试官方列出的jsDelivr地址；在设备上筛选、转换后存入MMKV，后续离线读取。首次下载失败时不显示句子，下次进入课表时重试。

旧工作区如果仍有此前生成的`shared/src/commonMain/resources/MR/files/hitokoto_sentences.json`，需要删除该文件，避免资源生成器继续将其打包。

保留的分类为动画、漫画、游戏、原创、影视、诗词、哲学和网易云，与原打包句库一致。

句库来源：[hitokoto-osc/sentences-bundle](https://github.com/hitokoto-osc/sentences-bundle)。上游句库采用AGPL-3.0，并在[官方使用须知](https://sentences-bundle.hitokoto.cn/)中为其提供的超链接调用方式授予开源及授权传播豁免；本客户端通过这些官方链接直接下载。

### 第三方许可证

“我的→关于→开源软件许可”离线展示随包附带的许可证、版权声明和NOTICE。数据位于`shared/src/commonMain/resources/MR/files/open_source_licenses.json`，正常构建直接使用这份资源，无需访问许可证网站。

更新依赖后，在具备Python3.11及以上版本、curl和网络连接的环境中重新生成：

```bash
./gradlew updateOpenSourceLicenses --no-configuration-cache
```

需要代理时，可在运行该命令前设置`ALL_PROXY`。Gradle自身访问网络还需按本机环境配置Java代理。

生成任务以Android及当前Desktop平台实际解析的运行时产物为基础，合并项目元数据，提取JAR/AAR中的许可证和NOTICE，再补充原生组件及字体图标的许可。外部许可文件缓存在`build/license-sources`。补充来源和已核对的原生版本由`scripts/licenses/sources.json`维护；版本变更时需要同步核对，缺失许可正文会使生成失败。

原生依赖、素材及待核实事项见[第三方许可清单维护](第三方许可清单维护.md)。

### 开源分支：补充加解密实现

开源分支出于脱敏不包含`RsaCodec`、`CampusRunCrypto`、`WebVpnCrypto`的协议加解密实现与固定密钥，仅保留common中的expect接口。构建前需自行补齐各平台actual实现，具体实现方法不在本指南范围内。未补齐前相关目标无法编译，登录、校园乐跑和WebVPN相关功能不可用。下方构建命令适用于补齐实现后的工作区。

## Android

构建调试包和发布包：

```bash
./gradlew :androidApp:assembleDebug
./gradlew :androidApp:assembleRelease
```

构建产物在`androidApp/debug/`和`androidApp/release/`，文件名形如`ink.chyk.pass.<版本>-kmp-debug.apk`与`ink.chyk.pass.<版本>-kmp.apk`。

签名：由Apksign插件签名（不跟Android Studio中的签名配置），在`local.properties`中配置：

```properties
releaseStoreFile=/path/to/keystore.jks
releaseStorePassword=<口令>
releaseKeyAlias=<别名>
releaseKeyPassword=<口令>
```

发布包默认开启R8混淆，规则见`androidApp/proguard-rules.pro`。

安装到设备：

```bash
adb install -r androidApp/release/ink.chyk.pass.<版本>-kmp.apk
```

## PC

调试临时运行：

```bash
./gradlew :desktopApp:run
```

编译验证与打包：

```bash
./gradlew :desktopApp:build
./gradlew :desktopApp:packageDistributionForCurrentOS
```
